# 方格教育 & 笃行明辨教育 - 门户网站建设方案（初版）

适用于：

* 方格教育（公考方向）
* 笃行明辨教育（考证方向）

建设目标：

个人认为：  
应以低成本、低维护、高稳定性为原则，快速建设企业门户网站，用于企业展示、品牌宣传、新闻公告及课程介绍等用途。

---

# 一、域名选择方案

## 1. 域名选择原则

企业门户网站域名应满足以下要求：

* 简短易记
* 方便输入
* 具有教育行业辨识度
* 可用于企业邮箱
* 便于后续品牌宣传

考虑到后续可能需要：

* 企业邮箱
* 宣传印刷
* 微信公众号绑定
* 企业微信
* 名片及海报使用

因此建议优先选择：

```text
.com 
.cn
```

# 二、技术选型方案

## 1. 建设原则

由于企业目前属于初期阶段，因此网站建设应优先考虑：

* 低成本
* 快速上线
* 稳定可靠
* 易于维护
* 非专业技术人员也可简单管理

因此不建议采用：

* 高成本云集群
* 微服务架构
* 复杂容器编排
* 高运维要求方案

避免后续维护困难及资源浪费。

---

# 2. 推荐整体架构

## 推荐架构

```text
                用户访问网站
                        │
                        ▼
            域名（DNS解析）
                        │
                        ▼
        Tunnel 网络穿透 / CDN
        （负责公网访问与安全防护）
                        │
                        ▼
                    Nginx
        （网站入口 / Web服务器）
                        │
                        ▼
                WordPress
        （网站内容管理系统）
                        │
                        ▼
                    Linux
            （整个服务器操作系统）
                        │
                        ▼
                实体服务器
        （实际运行网站的硬件设备）
```

---

# 3. 各组件说明

## （1）实体主机

采用本地实体主机部署。

### 推荐原因：

* 成本低于长期云服务器租赁
* 后期可复用
* 性能稳定
* 易于本地管理
* 适合小型门户网站

### 推荐配置

| 配置项 | 推荐配置               |
| --- | ------------------ |
| CPU | Intel i3 / Ryzen 3 |
| 内存  | 8GB                |
| 存储  | 256GB SSD          |
| 网络  | 千兆网卡               |
| 系统  | Linux              |

### 预算范围

```text
2000 ~ 3500 元
```

即可满足当前需求。

---

## （2）Linux 系统

使用：

* Ubuntu Server
* Debian

### 优点：

* 免费
* 稳定
* 占用资源低
* 社区成熟
* 长期维护方便

---

## （3）Nginx

作为网站服务器及反向代理。

### 优点：

* 性能高
* 占用资源低
* 稳定性优秀
* 适合门户类网站

---

## （4）Tunnel 网络方案

由于办公室网络无公网 IP，因此采用 Cloudflare Tunnel 方案实现外网访问。

### 优点：

* 无需公网 IP
* 无需额外购买高价专线
* 自动 HTTPS
* 可隐藏源站
* 安全性较高
* 成本极低

同时结合：

* CDN
* 线路优选

提高访问稳定性。

---

## （5）WordPress 内容管理系统

网站后台采用：

* WordPress

作为企业内容管理平台。

### 适合原因：

* 成熟稳定
* 上手简单
* 适合新闻公告发布
* 适合课程介绍
* 非技术人员也可使用
* 插件生态丰富

后续无运维经验员工可自行发布：

* 新闻
* 公告
* 图片
* 招生信息

无需程序员长期维护。

# 四、方案优势

## 1. 成本低

相比传统云服务器长期租赁方案：

本方案：

* 初期投入低
* 后续维护成本低
* 无需高额公网 IP
* 无需专业运维团队

适合初创教育机构。

---

## 2. 易于维护

整体结构简单：

```text
Linux
+
Nginx
+
WordPress
```

属于成熟稳定方案。

即使后续维护人员变更，也容易接手。

---

## 3. 快速上线

由于采用成熟技术方案：

* 网站搭建周期短
* 内容发布简单
* 可快速投入使用

适合企业前期宣传需求。

---

## 4. 稳定性高

门户网站本身访问量较低：

预计：

```text
几十人/天
```

当前方案完全足够。

同时：

* Nginx
* Linux
* WordPress

均为全球广泛使用的成熟方案。
